Shows the current power profile using a glyph. Left-click steps forward through the available profiles, right-click steps back, and scrolling does the same - all rebindable as [widget actions](/hyprbar/bar/actions/).

This widget has no settings of its own beyond the shared ones (`scale`, `enabled`, capsule styling, actions).

```toml
[widget.power_profile.actions]
scroll_up = "none"    # leave the wheel alone
scroll_down = "none"
```

**Command-line controls:**

```sh
hyprbar msg power-set balanced
hyprbar msg power-cycle
```

`power-set` activates a named profile such as `performance`, `balanced`, or `power-saver`. `power-cycle` switches to the next available profile and wraps to the first. See [System Controls → Power profile](/hyprbar/ipc/system-controls/#power-profile) for service requirements and command details.
