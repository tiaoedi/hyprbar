This fork does not provide a Nix flake, nixpkgs package, Home Manager module, Hjem module, or binary cache. The upstream
Nix definitions targeted Noctalia v5.2.1 and were removed rather than presenting an unverified package as Hyprbar support.

NixOS users may adapt the source-build instructions in [`BUILDING.md`](../../../BUILDING.md), but Nix dependency names,
build steps, and runtime behavior have not been validated for this fork.

Hyprbar's runtime configuration uses its own XDG directory names. It does not automatically reuse the source project's configuration.
The plugin runtime namespace and plugin IDs remain compatibility identifiers where used.
