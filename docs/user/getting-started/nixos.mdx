This fork has no maintained Nix flake, nixpkgs package, Home Manager module, Hjem module, or binary cache in this
repository. The source project's package and module examples do not install this fork and must not be relabeled as Hyprbar.

The upstream Nix packaging files are inherited but have not been validated for Hyprbar. For now, use the dependency and
source-build guidance in [`BUILDING.md`](../../../BUILDING.md); Nix-specific build instructions are not yet verified.

Hyprbar's runtime configuration uses its own XDG directory names. It does not automatically reuse the source project's configuration.
The plugin runtime namespace and plugin IDs remain compatibility identifiers where used.
