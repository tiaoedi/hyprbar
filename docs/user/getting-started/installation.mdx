Hyprbar is an independent fork based on the Noctalia v5.2.1 source. It is not maintained or endorsed by the original team. Source build and tests were run on Fedora 44 x86_64; no prebuilt RPM is published yet.

## Fedora 44 x86_64

No prebuilt RPM is available yet. To build from source, install the Fedora dependencies listed in [`BUILDING.md`](../../../BUILDING.md), clone the repository, then run `just configure release`, `just build release`, and `sudo just install release` from the repository root. This source installation does not change compositor configuration or enable autostart.

## Build from source

For dependency lists and release/debug build instructions, see [`BUILDING.md`](../../../BUILDING.md). Distribution-specific package names outside Fedora 44 are inherited build notes, not verified support claims for this fork.

## Start the shell

Run `hyprbar --daemon` from a Wayland session. In Hyprland, add this to the compositor configuration to start it at login:

```ini
exec-once = hyprbar --daemon
```

For Niri, use the syntax in the [Niri compositor guide](../compositor-settings/niri.mdx). The executable can also be started from the installed `dev.hyprbar.Hyprbar` desktop entry.

## Migrate an existing configuration

Hyprbar stores its configuration, state, data, cache, and IPC under Hyprbar-specific XDG paths. It does not silently reuse another shell's live configuration. To review the available migration options, run:

```sh
hyprbar config import-noctalia --help
```

Preview is the default; use `--apply` only after reviewing the proposed changes. See the configuration and CLI references for the migration details.

## Compatibility

This fork was run on Fedora 44 with Hyprland 0.56.2. Niri startup configuration syntax was validated, but Niri runtime was not verified. The source contains compositor integrations inherited from upstream; actual behavior depends on each compositor's protocols and is not claimed as tested here. Audio features require a working PipeWire/WirePlumber session.
