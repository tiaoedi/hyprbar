Hyprbar is a fork based on the Noctalia v5.2.1 source tree. This repository currently maintains local Fedora RPM packaging
only; there is no public Hyprbar repository or prebuilt release. Do not use upstream package commands for this fork.

## Fedora 44+

Build a local RPM from the source tree using [`packaging/rpm/README.md`](../../../packaging/rpm/README.md). For the exact
compiler dependencies and source build workflow, see [`BUILDING.md`](../../../BUILDING.md). The RPM has not been published.

The package includes the GNU Linux-libre Freedo artwork. Its license and trademark conditions are documented in
[`FREEDO-NOTICE.md`](../../../assets/licenses/FREEDO-NOTICE.md); do not redistribute a build carrying the mark publicly
until its use has been clarified with FSFLA.

## Other distributions

Build from source using `BUILDING.md`. Dependency package names and runtime behavior outside Fedora 44 have not been
validated specifically for Hyprbar.

## Start the shell

Run `hyprbar` from a Wayland session for foreground testing, or add `hyprbar --daemon` to the compositor's startup
configuration after testing. The desktop entry is `dev.hyprbar.Hyprbar.desktop`.

Hyprbar stores its configuration, state, data, cache, and IPC under Hyprbar-specific XDG paths; it does not reuse the
source project's live configuration automatically. See the migration command in the configuration/CLI reference before
copying any settings.

## Compatibility note

Existing plugins use the `hyprbar.*` runtime API namespace and `hyprbar-glyph:` icon prefix. Those identifiers are
intentionally retained for compatibility; this does not change Hyprbar's product identity.
