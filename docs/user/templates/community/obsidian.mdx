Hyprbar does not currently ship a bundled Obsidian CSS template or verify a dedicated integration. Community instructions and snippets are maintained independently and may not match the current Hyprbar configuration or template format.

Hyprbar's general user-template mechanism is documented in [Templates](/hyprbar/theming/templates/). Review any third-party CSS and commands before using them.
