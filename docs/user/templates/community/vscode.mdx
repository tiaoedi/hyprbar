Hyprbar does not currently ship a bundled Visual Studio Code theme template or verify a dedicated editor integration. Third-party extensions are maintained independently and are outside the Hyprbar release support boundary.

The shell's palette and template systems remain available for future Hyprbar-maintained integrations. Check this page again when a supported template is added.
