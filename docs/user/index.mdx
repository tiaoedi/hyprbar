Hyprbar v5 is a new generation of the shell, with a native runtime, refreshed UI, and a configuration model built for the current desktop experience.


If you are setting up Hyprbar for the first time, start with [Installation](/hyprbar/getting-started/installation/), then [Running Hyprbar](/hyprbar/getting-started/running-the-shell/) for compositor startup and keybind setup. Once the shell is installed, [How configuration works](/hyprbar/configuration/) explains where settings live and which file wins when the GUI and your config both set the same option.

:::caution[Moving from v4?]
- v5 installs separately and does not replace v4.
- v4 settings are not migrated, but both versions can coexist on most distributions.
- Update any compositor keybinds that launch Hyprbar commands.
:::

## Topics

- **[Installation](/hyprbar/getting-started/installation/)** - Local Fedora RPM and source-build guidance; other distro packages are not maintained by this fork.
- **[Running Hyprbar](/hyprbar/getting-started/running-the-shell/)** - Start the shell, run it from your compositor, and wire up keybinds.
- **[How configuration works](/hyprbar/configuration/)** - Config files, GUI-managed overrides, load order, and hot reload.
- **Greeter integration** - Optional compatibility with a separately installed login greeter; configure that component independently.
- **[Shell](/hyprbar/configuration/shell/)** - Global UI scale, fonts, animations, shadows, OSD, lock screen, and keybinds.
- **[Hooks](/hyprbar/automation/hooks/)** - Advanced event-driven automation.
- **[Launcher](/hyprbar/launcher/)** - Application search, calculator, emoji picker, and wallpaper browser.
- **[Control Center](/hyprbar/control-center/)** - Home tab, sidebar, shortcuts, and screen time.
- **[Bars](/hyprbar/bar/)** - Top, bottom, left, and right bars, including per-monitor changes.
- **[Widgets](/hyprbar/bar/widgets/)** - The clock, tray, volume, workspaces, media, and other things you place inside a bar.
- **[Dock](/hyprbar/dock/)** - Optional app dock, pinned apps, running apps, and auto-hide.
- **[Desktop widgets](/hyprbar/desktop/widgets/)** - On-desktop widgets, edit mode, and state file layout.
- **[Wallpaper & backdrop](/hyprbar/desktop/wallpaper/)** - Wallpaper folders, automation, per-monitor choices, and overview backdrop.
- **[Theme](/hyprbar/theming/)** - Built-in themes, wallpaper colors, and dark/light mode.
- **[Palette](/hyprbar/theming/palette/)** - Color roles, custom palette files, and terminal colors.
- **[App Theming](/hyprbar/theming/app-theming/)** - Generated themes for terminals, editors, browsers, and other apps.
- **Services** - [Audio](/hyprbar/services/audio/), [Brightness](/hyprbar/services/brightness/), [Calendar](/hyprbar/services/calendar/), [Idle](/hyprbar/services/idle/), [Night Light](/hyprbar/services/night-light/), [Notifications](/hyprbar/services/notifications/), and [Weather](/hyprbar/services/weather/).
- **[IPC](/hyprbar/ipc/)** - Commands for keybinds, scripts, automation, and hooks.
- **[Plugins](/hyprbar/plugins/)** - Install and configure plugins: custom bar widgets, shortcuts, and services in Luau.
