# Fedora RPM build

The RPM spec is for Hyprbar built from this source tree. `Source0` is a local source archive; create it from the repository root and keep generated build directories out of the archive:

```sh
version=$(tr -d '\n' < VERSION)
mkdir -p "$HOME/rpmbuild/SOURCES"
git ls-files -co --exclude-standard | tar -czf "$HOME/rpmbuild/SOURCES/hyprbar-${version}.tar.gz" \
  --transform="s,^,hyprbar-${version}/," -T -
RPM_BUILD_NCPUS=8 rpmbuild -ba packaging/rpm/hyprbar.spec
```

The spec builds with Fedora's Meson macros, runs the test suite with isolated HOME/XDG directories, stages the shell assets and desktop entry, and generates Bash, Zsh, and Fish completions from the built binary. It does not install Hyprbar on the host.

The build dependencies are based on the Fedora package list in `BUILDING.md`; Fedora 44 uses `libglvnd-devel` to provide EGL/GLES pkg-config modules. Runtime shared-library requirements are generated by RPM's dependency scanner. Optional runtime integrations (such as `git`, UPower, DDC/CI, and a running PipeWire/WirePlumber session) are not forced as hard dependencies.
